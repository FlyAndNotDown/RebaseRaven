关于 RebaseRaven。

RebaseRaven 是什么？

RebaseRaven 是基于 Rust 与 Tauri 构建的免费开源桌面图形客户端，用于 Git 仓库与 Perforce 工作区。在 Windows x64 与 macOS Apple Silicon 上审阅差异、追溯历史、准备 Git 提交、管理 Changelist 和 Shelf，并解决冲突。

RebaseRaven 如何使用 Rust？

Rust 用于桌面后端，Tauri 提供应用外壳，界面由 React 与 TypeScript 构建。Git 与 Perforce 的仓库操作通过你安装的 Git 和 p4 可执行文件执行。

提供哪些平台的版本？

可下载 macOS Apple Silicon 和 Windows x64 版本。Linux 用户可以安装 Tauri 平台依赖后从源码构建。

需要安装哪些命令行工具？

操作 Git 仓库需要安装 Git，操作 Perforce 工作区需要安装 Perforce CLI（p4）。如有需要，可以在设置中选择可执行文件。Git LFS 仓库还需要安装 Git LFS。

支持 GitHub、GitLab 和自托管 Git 服务吗？

RebaseRaven 通过你安装的 Git 访问本地仓库，以及 HTTPS 或 SSH 远程仓库。连接 GitHub、GitLab、Gitea 等 Git 服务时，沿用现有凭据与配置。Pull Request 审阅等托管平台功能仍在对应 Git 服务中完成。

会转换或同步 Git 与 Perforce 仓库吗？

Git 仓库与 Perforce 工作区在 RebaseRaven 中是独立的工作流。应用不转换仓库历史，也不在 Git 与 Perforce 之间同步变更。

RebaseRaven 可以免费使用吗？

可以。RebaseRaven 免费使用，采用 MIT 开源许可证，源码与安装包均发布在 GitHub。

我的仓库存放在哪里？

本地仓库和工作区文件保存在你的设备上。远程操作通过 Git 或 Perforce 连接你配置的服务器。

演示会修改真实仓库吗？

不会。演示使用浏览器中的虚构数据，暂存、提交和搁置操作均不会影响真实仓库。
